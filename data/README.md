# Исходные данные

Каталог содержит два CSV-файла с измерениями ветровых турбин. Это исходные данные проекта, а не результат работы модели.

| Файл | Турбина | Записей | Период |
| --- | ---: | ---: | --- |
| `Dataset HackAlemAI для участников 11.03.2023-28.02.2026 - turbine 1.csv` | 1 | 142 360 | 11.03.2023 00:00 — 31.01.2026 23:50 |
| `Dataset HackAlemAI для участников 11.03.2023-28.02.2026 - turbine 2.csv` | 2 | 149 499 | 11.03.2023 00:00 — 31.01.2026 23:50 |

## Формат

CSV использует запятую в качестве разделителя. В каждой строке пять полей:

```text
ID,Статистическое время,Средняя скорость ветра(m/s),Нормализованная активная мощность,Средняя температура окружающей среды(°C)
```

Временные метки в доступных строках расположены на 10-минутной сетке. В полной сетке обнаружены пропуски: 9 992 слота для первой турбины и 2 853 слота для второй. При подготовке данных не следует автоматически считать такие интервалы нулевой выработкой.

## Использование

Оригинальные файлы должны оставаться неизменными. Производные наборы, подготовленные признаки и результаты экспериментов следует хранить вне исходных CSV либо в отдельных каталогах, добавленных вместе с соответствующим кодом.
