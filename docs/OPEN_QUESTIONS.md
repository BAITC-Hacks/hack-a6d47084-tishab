### Факты, проверенные на API (для контекста)

- Open-Meteo Single Runs API, модель `ecmwf_ifs`: запуски **00/06/12/18 UTC**, архив **с апреля 2024** по февраль 2026 включительно.
- Доступны высоты ветра 10/80/100/120/200 м, направление, порывы, температура, давление, влажность.
- GFS / ICON через Single Runs за прошлые даты **недоступны**.
- Обе турбины попадают в **одну ячейку сетки** ECMWF (43.620, 78.479), погода для них идентична.
- Время публикации запуска API **не отдаёт**, поэтому `available_at` — это допущение.
